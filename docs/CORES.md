# Cores do CLI

- `✓` verde: sucesso.
- `✗` vermelho: bloqueio ou erro.
- `!` amarelo: atenção ou correção manual.
- `i` ciano: informação ou etapa.

A cor reforça símbolos e rótulos; não é necessário memorizar a paleta. Arquivos, regras e mensagens ficam neutros para evitar uma saída excessivamente colorida.

A legenda curta aparece uma vez por execução do pipeline. O modo padrão é `NINFA_COLOR=auto`; também existem `always` e `never`. Quando `NO_COLOR` estiver definida, as cores são desativadas.
